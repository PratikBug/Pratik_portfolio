## Run the portfolio site

Use **Node.js 18+** (recommended: 20 LTS). If you use `nvm`, run `nvm use` in this repo (see `.nvmrc`).

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

Re-parse README only:

```bash
npm run parse-readme
```
